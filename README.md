# Neil Budol Portfolio

React + Vite + Tailwind CSS + Framer Motion portfolio.

## Updates in this build
- Added IT Support & Technical Operations to the Skills Matrix.
- Added individual GitHub repository links for public projects visible on Neil's GitHub profile.
- PNP Project Management System now links directly to its repository.
- Added Pokémon Memory Match, Penguin Fishing, Coco Tea, Mercedes-Benz Reimagining, and Facebook UI project cards.

## Run locally
```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal (normally http://localhost:5173).
